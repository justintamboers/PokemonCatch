To Add pokemons into the database 

In visualstudio2022

1. Start the project first and close it so the database gets created
2. Go on the top to view -> SQL Server Object Explorer
3. Add new database name it Pokemon 
4. Right click Pokemon -> New Query -> fill in the sql file here
5. Replace in PokemonData line 37 with your connection string
6. Replace in PokemonWindow.xaml.cs line 28 with the folder path for the map Pokemon with all the png's
